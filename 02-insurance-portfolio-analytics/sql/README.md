# SQL Scripts

## Purpose

Store the MySQL scripts developed throughout the Insurance Portfolio Analytics project.

## Planned Structure

Scripts will be organised into numbered stages so they can be executed and understood in sequence.

- Database creation
- Table creation
- Synthetic sample data
- Cross-database queries and joins
- Premium data integration
- Claims data integration
- Portfolio and business reporting
- Data-quality and reconciliation checks

## Learning Objectives

- Understand how MySQL databases and tables relate.
- Query tables across multiple databases on the same MySQL server.
- Identify join keys, grain and relationship cardinality.
- Aggregate premium and claims data without double-counting.
- Calculate portfolio, group, department and business-level loss ratios.
- Validate query results against source data.

## Conventions

- Use descriptive database, table and column names.
- Number scripts in execution order.
- Include comments explaining business logic.
- Use synthetic data only.
- Document assumptions and dependencies.

## Status

Initial project setup. The first practical exercise will focus on joining data across two MySQL databases.
