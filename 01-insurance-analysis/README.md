# Insurance Data Analysis

## Project Overview

This project explores how SQL can be used to answer business questions using insurance data.

The aim is to develop practical skills in database querying, data quality, data relationships, and business-focused analysis.

## Objectives

- Translate business questions into SQL queries.
- Explore relationships between insurance data entities.
- Apply joins, aggregations, Common Table Expressions (CTEs), and conditional logic.
- Identify data quality issues and validate results.
- Explain query logic, assumptions, and findings in business terms.

## Project Contents

SQL scripts, example datasets, query explanations, and analysis results will be added as the project develops.

## Status

In progress — project structure and analysis exercises are being developed.
